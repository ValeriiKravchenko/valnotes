# valnotes

Старая версия личного сайта: интерактивы по IT-книгам (раздел `library`) и игровые симуляторы по рабочему стеку (раздел `simulators`: git-тренажёр и тренажёр английского). Делалась для себя и узкого круга, не коммерческий проект.

> Статус: архив и лаборатория. Развитие сайта переехало в репозиторий [valkravchenko](https://github.com/ValeriiKravchenko/valkravchenko), актуальная версия: <https://valkravchenko.com>. Библиотека, git-тренажёр (разделы 1–6) и тренажёр английского перенесены туда; новые разделы и правки делаются там. Здесь код остаётся для справки и опытов, тренажёры могли содержать неточности по сравнению с настоящими инструментами.
>
> Домен `valnotes.com` не продлевается: он работает до 27.03.2027, после этого адрес перестанет открываться. Ссылки на него лучше заменить на `valkravchenko.com`.

Стек: Vite, React 19, TypeScript, Tailwind, react-router 7.

## Структура

- `app/` — приложение (Vite + React), вся сборка отсюда
- `app/src/pages/` — страницы-маршруты, тонкие
- `app/src/data/` — текстовая начинка сайта (словари, контент)
- `app/src/trainers/` — тренажёры, каждый в своей папке: `engine/` — логика и тесты без React, `locales/` — словари интерфейса
- `docs/` — материалы, не попадают в сборку (спецификации, справочные источники по тренажёрам)
- `.claude/agents/` — роли субагентов, с которыми ведётся разработка

## Запуск

```
cd app
npm install
npm run dev
```

## Сборка

```

npm run build
```

## Тесты

