## Как пройти четыре миссии на localhost (`npm run dev`, затем `/simulators/git/inspecting`)

Открыв страницу, видно: терминал слева, справа — статус трёх областей и панель файлов, снизу —
четыре миссии «Что попробовать», все с пустой отметкой «—».

1. В терминале ввести `git log` и Enter → выводится история из трёх коммитов (сверху «Обо мне»,
   снизу «Первый коммит: структура страницы»); в панели миссий первая строка получает «✓» и
   зачёркивается.
2. Ввести `git log --oneline` → три строки с короткими хэшами; отмечается вторая миссия.
3. Ввести `git diff` → диф только по `index.html` (добавлен `<footer>© 2026</footer>`);
   отмечается третья миссия. Панель статуса при этом показывает `index.html` во всех трёх
   областях (working/index/HEAD) — они не совпадают, отсюда и сам диф.
4. Ввести `git diff --staged` (или `git diff --cached`) → диф только по `style.css`
   (`body { color: black; }` → `body { color: #222; background: #fafafa; }`); отмечается
   четвёртая, последняя миссия.

Кнопка «↺ Начать раздел заново» сбрасывает состояние и снятые отметки миссий к тому же
исходному seed. Также можно попробовать `git status`/`git status -s`, `git show`,
`git show HEAD~2`, `git log --oneline HEAD~2..HEAD` и намеренно неподдерживаемые формы
(`git log --graph`, `git add ...`) — честные отказы по правилу области, без выдумывания
поведения git.
