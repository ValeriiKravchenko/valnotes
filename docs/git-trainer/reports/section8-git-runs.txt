# Прогоны git 2.53.0, 26.09.2026, LC_ALL=C, GIT_CONFIG_GLOBAL=/dev/null, GIT_CONFIG_NOSYSTEM=1, GIT_PAGER=cat.
# Каталог прогона в выводе заменён на /work. Автор и коммиттер: Валера <valera@example.com>.
# Даты: каждая команда сдвигает часы на минуту, начиная с Mon Jun 1 10:00:00 2026 +0300, через GIT_AUTHOR_DATE/GIT_COMMITTER_DATE —
#   поэтому хэши воспроизводимы в пределах этого файла, но от порядка команд зависят. С хэшами source.html не совпадают.
# Исходная история — как seed раздела 8 в source.html (app.js, feature: fix + about, master: README).
# log.decorate=short задан через GIT_CONFIG_PARAMETERS: вывод здесь не на терминал, а при log.decorate=auto (по умолчанию)
#   git печатает подписи (HEAD -> master, tag: …) только на терминал. Так вывод совпадает с тем, что человек видит в терминале.
#   Отдельный блок в конце показывает разницу auto/short.
# <CR> — символ возврата каретки (\r) в выводе git. rebase печатает прогресс «Rebasing (1/2)<CR>», на терминале
#   следующая строка затирает его, и человек видит только последнюю строку («Successfully rebased …»).
# Формат: "$ команда", вывод (stdout+stderr), [exit код].
