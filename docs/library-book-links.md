# Ссылки «открыть» у книг библиотеки

Кнопка «открыть» на странице `/library/books` ведёт на файл книги в личном
Яндекс.Диске владельца. Список ссылок выдаёт структуру папок и имена файлов,
поэтому он не хранится ни в репозитории, ни на сервере: файл собирается на своей
машине и загружается в браузер на скрытой странице `/library/books/links`
(в меню её нет). Ссылки живут в localStorage этого браузера, и кнопки видны
только там. Остальные посетители их не видят.

## Сборка файла ссылок

```
node scripts/build-book-links.mjs <локальная папка Диска с книгами> <путь этой же папки на Диске>
```

Первый аргумент — путь к папке на локальном диске, где синхронизирован
Яндекс.Диск (например, папка, примонтированная из Windows). Второй — путь
этой же папки внутри самого Диска, каким он виден в веб-интерфейсе
(например, `/Программирование/Литература`).

Скрипт рекурсивно обходит папку, находит PDF и EPUB, сопоставляет их с
названиями книг из `app/src/data/library.ts` по имени файла без расширения
(без учёта регистра, лишних пробелов и символов, запрещённых в именах файлов Windows: `: ? " < > | * / \`) и пишет `book-links.json` в корень репозитория (файл в `.gitignore`).
Если у книги есть и PDF, и EPUB — берётся PDF. После запуска скрипт печатает
сводку: сколько книг сопоставлено и список книг, для которых файл не найден.

Если от прежней схемы остался `app/public/links.json`, скрипт его удаляет:
всё из `app/public` уходит в сборку и становится доступно любому посетителю.

## Загрузка в браузер

1. Открыть на сайте `/library/books/links`.
2. «Загрузить файл ссылок» → выбрать `book-links.json`.
3. На `/library/books` появятся кнопки «открыть».

Страница принимает только JSON-объект «название книги → ссылка», где каждая
ссылка начинается с `https://disk.yandex.ru/`. Иначе файл отклоняется целиком.

Загружать нужно на каждом устройстве и в каждом браузере отдельно, а также
заново, когда меняется состав файлов на Диске или список книг в `library.ts`.
Если очистить данные сайта в браузере, ссылки пропадут — тогда загрузить файл
снова. Пересобирать и выкладывать сайт ради ссылок не нужно.
